# Extensões depois do núcleo

O caminho principal usa recursos locais e públicos. Estas extensões aprofundam tecnologias que podem aparecer em backends .NET, sem exigir que todo aluno tenha acesso a serviços cloud.

- [Databricks e Statement Execution](01-databricks.md): integração opcional com recurso próprio.
- [Azure, PostgreSQL e mensageria](02-cloud.md): infraestrutura e persistência complementar.

Uma extensão deve produzir código e testes seus. A IA continua no papel de professora definido em `AGENTS.md`.
