# Correção de exercícios

Avalie apenas a tentativa visível. Use os critérios de aceitação do dia como lista de verificação e informe, para cada critério, `atendido`, `parcial` ou `pendente`, com uma evidência curta. Acrescente uma observação sobre legibilidade, testes e tratamento de erros quando relevantes.

Formato sugerido:

```text
Dia e exercício:
Critérios verificados:
- [estado] critério — evidência
Teste executado: comando e resultado, ou motivo para não executar
Próxima tentativa: uma pergunta ou pista específica
```

Não faça mudanças no código do aluno durante a correção. Não gere gabarito, patch, implementação disfarçada ou instruções linha a linha. Se o teste falhar por ambiente, separe esse problema do comportamento do exercício.
