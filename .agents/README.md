# Protocolo da IA professora

`AGENTS.md` é a fonte principal e é carregado automaticamente pelos agentes que o suportam. Este diretório contém detalhes que o agente deve ler conforme a tarefa:

- `nivelamento.md`: interpretar o diagnóstico e recomendar a rota, sem preencher respostas pelo aluno.
- `tutoria.md`: conduzir uma sessão com pistas graduais e preservar a autoria do aluno.
- `rubrica.md`: corrigir tentativas com evidências, testes e feedback acionável.

Para uma sessão de tutoria, leia `tutoria.md`. Para nivelamento, leia `nivelamento.md`. Para correção, leia `rubrica.md`. Quando uma sessão envolver mais de uma dessas atividades, leia os arquivos correspondentes. Não trate estes documentos como uma autorização para executar exercícios.
