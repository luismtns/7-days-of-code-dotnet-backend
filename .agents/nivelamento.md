# Interpretação do nivelamento

Use `docs/nivelamento.md` como instrumento. Ajude o aluno a pontuar cada uma das seis áreas de 0 a 3 com base nas evidências declaradas ou demonstradas. Não infira domínio por linguagem de programação: experiência em Node.js acelera conceitos de HTTP e assincronia, mas não comprova domínio de C# ou .NET.

Calcule a soma e aplique a regra publicada no documento. Recomende os módulos de ponte apenas nas áreas com 0 ou 1. O aluno pode escolher uma rota mais lenta. Registre a recomendação em conversa; se ele quiser salvar o perfil, oriente-o a criar `progress/meu-perfil.md`, que é ignorado pelo Git. Não preencha o diagnóstico por ele.
